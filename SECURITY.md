# Sécurité

- Ne commitez **jamais** de fichier `.env` contenant des secrets (Supabase, Stripe, etc.).
- En cas de fuite accidentelle de clés : révoquez-les dans les dashboards Supabase / Stripe et régénérez.
- Les signalements peuvent être ouverts via les issues GitHub du dépôt (pas d’adresse email dédiée pour l’instant).
